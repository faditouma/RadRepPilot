# X-ray teaching interface
1. Review individual Commons assets; retain rights, source findings and privacy checks separately.
2. Complete one radiograph quiz: context, sticky image, neutral questions, generated/editable report, immutable local submission, server-protected editorial draft corrections.
3. Add two other source-supported drafts, a coherent Learn/library/progress/tools shell, and a lightweight raster viewer; retain OHIF CT routes.
4. Verify desktop/tablet interactions, resume and answer-access boundaries; deploy only behind existing Vercel Authentication.

Draft feedback is read-only editorial testing for the protected preview's authorized Vercel team viewers. It is not a published learner answer or validated assessment. Actual author/reviewer edits and publication continue to require the existing Supabase editor roles. No reviewer identity, clinical approval or public editor role is created. Production feedback fails closed for unapproved content.

Existing palette and typography are retained; questions use explicit radio cards and a focused stepper rather than the full legacy form. No synthetic diagnostic images are used.
